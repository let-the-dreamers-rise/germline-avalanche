Try it

Tune an AI configuration, and keep a record of how you found it that anyone can check without trusting you.

Two steps. The first runs entirely in this page. The second records the same kind of search on Avalanche's Fuji test network, from a test wallet this page makes for you, and then verifies every step against the chain.

Step 2 · Avalanche Fuji test network, free

Record it on chain and verify it

Every configuration becomes an on-chain record of its parent and its score. Each child is bred by commit-reveal: you commit first, and the random seed comes from the hash of a block that did not exist yet, so nobody can pick their own mutation. At the end, the page re-derives every child from its parent and that seed.

Step 3

Use your own system

The examples above stand in for an eval. To tune your own prompt, agent or rules, describe the settings and give Germline a function that scores a configuration. That runs on your machine; only hashes and scores go on chain. The guide takes about ten minutes.

Already-live reference: the Germline registry on Fuji, with an honest child that verifies and a deliberately forged one that does not, re-checked on every push by public CI.

Open source: github.com/let-the-dreamers-rise/germline-avalanche. This page runs the same SDK code as the command line, bundled for the browser.
